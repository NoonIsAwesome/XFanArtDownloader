The GUI's Python runtime must not import or contain gallery_dl code, and the
worker must not import PyQt6. They are separate programs, built as separate
executables. Communication
is limited to ordinary URL / Cookie-file-path inputs and general JSON Lines
metadata, without shared Python objects, memory, or calls into the other's
internal functions. The main application's frozen dependency graph must exclude
gallery-dl; the worker's graph must exclude PyQt6 and Qt.

The Windows single-file distribution stores the separately built, unchanged
gallery-dl-helper.exe as data in the GUI's self-extracting archive. At runtime
the GUI launches that executable from the temporary extraction directory as a
child process. Its Python code is not added to the GUI's module archive or
loaded into the GUI interpreter. One downloadable file therefore contains two
separately executed programs; it does not create a shared Python runtime.
The separate build recipes are packaging/gallery-dl-helper.spec and
packaging/XFanArtDownloader.spec; root build.cmd runs them in that order.
