# 隱私說明 — FanArtDownloader 3.0

更新日期：2026-10-17

FanArtDownloader 是本機 Chrome 擴充功能。此版本沒有開發者營運的收集伺服器、分析追蹤或廣告服務，也不將工作紀錄同步到雲端。

## 登入與 Cookie

登入在正常 Chrome 的 X／Google 網站完成，擴充功能不要求輸入帳號密碼。程式只透過 `chrome.cookies.get` 讀取 `https://x.com/` 的 `ct0`，用於 X 網頁請求的 CSRF header；值只在請求處理所需的記憶體中使用，不寫入 IndexedDB、設定、備份或紀錄，也不匯出 Cookie 檔案。

向 X 發送請求時，Chrome 會自動附帶適用於 X 的現有登入 Cookie。程式不讀取 `auth_token` 值、不讀取 Google Cookie、不複製或解密瀏覽器 Cookie 資料庫，也不啟動遠端除錯瀏覽器。Google／X 網站本身如何處理登入，依各網站的政策。

## 本機保存的資料

介面設定保存在 Chrome 本機儲存，主題偏好另存於擴充功能的 localStorage。本機 IndexedDB 保存標籤、作者、貼文文字與日期、媒體網址、來源、分頁游標、下載狀態、檔名、Chrome 下載 ID、嘗試次數及錯誤等工作資料。這些資料用來去重、接續與補抓，可能包含只有目前帳號能看到的貼文資訊；請自行管理此 Chrome 設定檔的存取。

圖片與影片由 Chrome 寫入下載目錄。擴充功能可能讀取 Chrome 回傳的下載紀錄與檔案狀態，以核對本工具提交的下載。下載紀錄及磁碟上的媒體檔案，也受 Chrome 與作業系統的管理。

使用者主動匯出的 JSON 備份包含媒體紀錄與作者，可能包含貼文文字、媒體網址及下載檔案資訊；不包含登入 Cookie。備份檔案由使用者自行保存及分享，請先確認其中內容。

## 網路連線

工作需要向 X 送出選定的標籤搜尋、作者或貼文查詢，向 `abs.twimg.com` 取得網頁介面資料，並向 `pbs.twimg.com`／`video.twimg.com` 取得圖片、預覽或影片。X 與其媒體服務會接收到網路請求及正常連線資訊；「本機處理」不代表離線下載。

從 X 網頁 JavaScript 資源讀取的 query ID 與動畫資料只作文字解析，不下載並執行遠端程式碼。作者資訊中的外部連結，只有使用者主動開啟後才會前往對應網站。

## 權限用途

- `cookies` 與 X 網域權限：讀取 X 的指定 `ct0` 並傳送工作請求。
- X 及其靜態／媒體網域權限：讀取貼文、分頁與媒體資源。
- `downloads`：開始下載、核對結果與顯示 Chrome 下載紀錄。
- 本機儲存相關權限／IndexedDB：保存設定、歷史、佇列及游標。
- `alarms`：Chrome 運作時喚醒下一批或等待重試的工作。

實際授權清單以安裝資料夾中的 `manifest.json` 為準。程式未要求 Google 網域的 Cookie 存取權。

## 保留、刪除與更新

資料保留在安裝此擴充功能的 Chrome 設定檔。更新原資料夾並重新載入同一擴充功能時會繼續使用本機資料；解除安裝擴充功能會清除其儲存資料。已下載媒體、匯出的 JSON 備份及 Chrome 自己的下載紀錄不會因此一併刪除，請在檔案管理員或 Chrome 另行管理。
